主密码

创建分组会复制当前 Profile 的 Cookie（包括其他网站的登录 Cookie）及当前网站存储。运行中会读取受管标签的 URL、请求/响应与自定义 Header，用于本机隔离和缓存；不会上传到开发者服务器。保存的会话使用主密码加密，密码仅在本机使用。网页自己的 IndexedDB / CacheStorage 不属于主密码加密范围。

请使用独立且足够长的主密码。没有找回功能，遗忘密码无法恢复已加密的会话。旧版明文数据会在加密写入验证成功后删除；浏览器/系统旧备份可能仍有副本。

阅读隐私说明

网页直接在 Chrome 中运行，无画面转发。新分组复制当前 Profile Cookie 和当前站点的 localStorage / sessionStorage。组内 Cookie 与 localStorage 共享，其他分组独立。 支持范围：不继承 IndexedDB；禁用 Worker、Service Worker、WebSocket；网站新标签页自动加入当前分组。需保持 Chrome 的调试连接；取消连接会停止会话。尚不保证任意网站兼容。
