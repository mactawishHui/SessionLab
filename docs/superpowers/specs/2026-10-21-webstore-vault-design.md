# Chrome Web Store 上架与主密码保护

用户已同意：增加主密码解锁，重启 Chrome 后首次使用输入一次，保留会话保存/恢复。上架目标为 Chrome Web Store 公共发行；开发者账号注册、协议与付款由用户完成。

## 实现边界

独立 vault.js 使用 Web Crypto PBKDF2-SHA256（600000 次、随机 16 字节盐）派生 AES-256-GCM 密钥；每次保存采用随机 12 字节 IV 和带版本的认证附加数据。整个 nativeGroups 数据在 chrome.storage.local 中改为密文 nativeVault；不存密码、不持久化明文派生密钥。会话密钥只放 chrome.storage.session，限定 TRUSTED_CONTEXTS，以允许 MV3 worker 回收后恢复；浏览器重启、扩展重新加载后需要解锁。

旧版 nativeGroups 仅在用户设置密码并确认披露后迁移；先成功写密文并验证，再移除旧键，失败保持原数据可恢复。保留原扩展 key/ID 及组对象内部结构。密码错误或数据被改动均拒绝解密，不覆盖原密文。旧数据存在时不得被新空仓覆盖。不得记录密码或 Cookie。无找回密码或后台重置功能。

UI 增加设置/解锁表单和明确披露：创建组复制 Profile Cookie（含其他网站 Cookie）、站点存储、Header 与请求内容用于本机隔离；密码仅在本机使用，遗忘无法恢复。首次设置要求确认披露和密码至少 12 字符、确认一致。锁定时不暴露组名/Header/URL，不接受普通业务命令。若存在会话绑定但无法解锁，停止受管标签，禁止借用普通 Profile 继续加载。

默认不增加手动锁定、改密码、数据导出或云同步，避免扩张会话生命周期。本次仅实现用户同意的启动解锁。网站 IndexedDB/CacheStorage 等页面存储不在 vault 加密范围，必须如实披露；Chrome Web Store 的最终合规仍需核验。
