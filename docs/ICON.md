# 图标来源

使用内置 image_gen 工具生成，原始透明 PNG 位于 assets/icon-source.png。安装用尺寸为 extension/icons/ 下的 16、32、48、128 PNG，经去除外围透明留白、保留安全边距和标准缩放导出。没有上传任何用户截图或账户资料。

最终提示词：

> Use case: logo-brand. Create one polished icon for Session Lab, a Chrome browser extension that keeps separate login sessions for browser tab groups. A simple bold mark of three rounded overlapping browser-tab shapes, separated and connected by clean negative space, subtly suggesting an S. Match the product's existing forest-green and warm off-white UI. Minimal flat geometric design, crisp broad shapes readable at 16px, no lettering, no tiny details, no mockup, no shadows outside the mark. Centered square composition with safe padding. Transparent background.
